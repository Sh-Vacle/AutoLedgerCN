# 隐私与资源边界

用户主动授予通知读取权限后，应用可以访问通知标题和正文；仅监听用户选择的应用。流水、原通知和诊断在应用数据目录中保存。代码没有INTERNET权限，但这不等于所有设备厂商行为均已审计。

此次候选将 `allowBackup` 设为false，并为旧式fullBackup和Android12+ cloud-backup/device-transfer补充数据域排除。没有实测各厂商系统备份/迁移，不能承诺所有OEM均按相同方式执行。CSV由用户显式导出，仍可能含商户/账户/备注，需自行保存和脱敏。

所有原角色PNG、立绘、衍生logo/图标和design_refs未复制到候选。装饰资源使用本次自行编写的矩形账本/线条矢量；不是模仿角色形象的AI衍生图。内部资源名和持久化ThemeMode枚举保持历史兼容，显示名为清浅/暖色。

Gradle wrapper JAR是必要工具文件，保留其来源及上游许可，不把它当本项目原创代码。业务源码按用户提供的个人项目来源说明和最终授权公开；来源审查的局限及第三方许可见 [第三方材料](../THIRD_PARTY_NOTICES.md)。未新增业务源码许可证。
